Privacy Policy — sessfork Companion Extension

Effective Date: November 26, 2026 · Open-Source MIT License · Project: wasabihu/sessfork

1. Summary

The sessfork Companion Extension is an open-source, auditable, zero-dependency browser extension that runs exclusively on your local device. It has no background service worker, makes zero outbound network requests, collects zero analytics or telemetry, and never transmits any data to the author or any third party.

2. Data Accessed & When It Is Accessed

The extension accesses browser data only when you explicitly open the popup and click a sync button ("Fork This Site" / "Fork Selected"):

  • Cookies (via chrome.cookies.getAll): strictly scoped to the domain of the tab(s) you explicitly select.
  • LocalStorage (via chrome.scripting.executeScript): strictly scoped to the origin of the tab(s) you explicitly select, verified against the tab's authoritative origin.
  • Open Tab URLs (via chrome.tabs.query): read locally inside the popup UI solely to display the current site and let you optionally choose other open tabs in the same window.
  • UI Language Preference: saved locally in the extension popup's localStorage (sessfork_ui_lang) only.

3. How Data Is Stored & Transferred

  • Selected session data is sent solely over local Chrome/Edge Native Messaging (com.wasabihu.sessfork) to the local sessfork-mcp binary installed by you on the same machine.
  • The local binary validates domain scope and writes a Playwright-compatible storageState snapshot to ~/.sessfork/state.json (strict user-only permissions, 0600 on Unix) so your local headless AI agent can browse without stealing browser window focus.
  • No remote transmission: Neither the extension nor sessfork-mcp uploads, logs, sells, or shares cookies, tokens, browsing history, or personal data with any remote server.

4. Data Retention & Deletion

You remain in full control of your local session snapshots at all times. You can delete any individual site's synced session or wipe all synced sessions in one click from the extension popup (Synced Sessions → × / Clear All), or delete ~/.sessfork/ directly from disk.

5. Permissions Justification

  • cookies: Read cookies (including HttpOnly session cookies) strictly for the domain explicitly triggered by the user.
  • activeTab & scripting: Read window.localStorage from the user-selected tab(s) when the user clicks sync.
  • nativeMessaging: Send the user-selected snapshot directly to the user's local com.wasabihu.sessfork Rust Native Messaging host on the same computer.
  • http://*/* & https://*/*: Required so the user can choose to fork any logged-in web application (including internal portals and http://localhost dev servers) without hardcoding specific websites.

6. Open Source & Contact

The entire source code is publicly auditable at github.com/wasabihu/sessfork/tree/main/extension. For privacy or security inquiries, please open an issue or follow our private disclosure process in SECURITY.md.

隐私政策 — sessfork 伴生扩展

生效日期：2026 年 11 月 26 日 · MIT 开源协议 · 项目仓库：wasabihu/sessfork

1. 核心承诺

sessfork 伴生扩展是一款开源、零依赖、完全可审计的浏览器扩展，100% 仅在您的本机运行。本扩展不包含任何后台常驻脚本（无 service_worker）、不发起任何对外网络请求、不包含任何统计/埋点/遥测代码，也绝不会将任何数据发送给作者或任何第三方服务器。

2. 访问的数据与触发时机

本扩展仅在您手动点开弹窗并点击同步按钮（「同步当前站点」或「一键同步已选」）时，才按需读取以下本机数据：

  • Cookie（通过 chrome.cookies.getAll）：严格限定为您显式选中的目标域名。
  • LocalStorage（通过 chrome.scripting.executeScript）：严格限定为您显式选中的标签页源（Origin），并二次校验标签页来源未发生跳转。
  • 当前窗口标签页网址（通过 chrome.tabs.query）：仅在弹窗内本地展示当前站点及可选的其他已打开标签页列表。
  • 界面语言偏好：仅在本扩展弹窗本地 localStorage 保存中英文切换选项（sessfork_ui_lang）。

3. 数据流向与本地存储

  • 您选中的登录态快照仅通过浏览器原生本机通信（Native Messaging，com.wasabihu.sessfork）发送给您本机安装的 sessfork-mcp 程序。
  • 本机程序在严格校验域名白名单后，将数据原子写入本机 ~/.sessfork/state.json（仅限当前用户可读），供您本机后台无头 AI Agent 浏览器使用。
  • 零外网传输：任何 Cookie、令牌或浏览记录均不会离开您的设备。

4. 数据清理与自主控制

您对本地快照拥有 100% 控制权：可随时在弹窗「已同步站点」列表中一键删除单个站点或清空全部数据，或直接删除本机 ~/.sessfork/ 目录。

5. 开源审计与联系方式

扩展全部源码公开于 github.com/wasabihu/sessfork/tree/main/extension。如有隐私或安全疑问，请前往 GitHub Issues 或查阅 SECURITY.md。
